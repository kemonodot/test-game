# 仮面葬送 — 異骸の遠征

Godot 4の縦画面オート戦闘RPG、Android用0.1.3です。4人を編成し、遠征で育成と装備を進め、3体の主に挑みます。初回討伐後は融合か複写で新しい個体を迎えます。

[ZIPをダウンロード（約28MB）](https://github.com/kemonodot/test-game/archive/refs/heads/apk-masked-requiem-v0.1.3.zip)

[APKを直接ダウンロード](https://github.com/kemonodot/test-game/raw/refs/heads/apk-masked-requiem-v0.1.3/MaskedRequiem-v0.1.3.apk)

## インストール・更新

1. ZIPを保存し、Androidの「ファイル」アプリで展開します。
2. 展開されたフォルダーの `MaskedRequiem-v0.1.3.apk` を開きます。
3. 必要な場合、ファイルアプリからのインストールを許可します。
4. 以前の版が入っていれば「更新」で上書きします。アンインストールは不要です。
5. 「仮面葬送」を起動し、装備・血統・仲間詳細でカードの上から縦スワイプして確認してください。

Android 7以降、arm64端末、OpenGL ES 3対応が必要です。iPhone/iPadにはAPKをインストールできません。

## 0.1.3の修正

- 装備・血統・詳細画面で、カードやボタン上からスクロールできるようにしました。
- スワイプを装備・分解・転職のタップと誤認しないよう、ネイティブのスクロール開始通知で押下を取り消します。
- 仲間選択メニューは指を離したときに開きます。スクロール開始時には開きません。
- 指を置いた際の自動フォーカスによる位置飛びを抑えました。
- 遠征の更新による一覧再生成をスクロール終了まで保留し、操作を途中で切らないようにしました。

同じアプリID・署名証明書、バージョンコード4です。戦闘・育成・出生のルールとセーブ形式は変更していません。約28MBの軽量フォント版を維持しています。

## 操作

「仲間」で4人を編成・転職・訓練し、「装備」で遺物を交換します。「通常遠征」で自動周回、「遠征」で主に挑みます。敗北で仲間や遺物は失いません。戦闘速度は1・2・4倍を選べます。保存は自動で、設定から手動保存と初期化もできます。

## 確認範囲

実際のGodot4.6.3のシーンにタッチイベントを送り、修正前は29項目中7項目の問題を再現しました。追加ケースを含む修正後は37項目成功、0失敗・0スキップです。カード/ボタン上のスワイプ、通常の装備タップ、小さな指の揺れ、メニュー選択、スクロール中の進行更新、詳細モーダルを含みます。保存・バックグラウンド復帰の既存30項目も成功しました。

APKの署名・整列・ZIP・Provider設定・バージョン・証明書を検証済みです。修正前0.1.2のスマホ起動はユーザーから報告されました。0.1.3のAndroid実機タッチ・起動の再確認は未実施です。headless試験の合成タッチはAndroid実機の確認とは区別しています。

ゲーム本体の既存6300戦等の大量戦闘試験は、コアロジックを変更していないため再実行していません。このブランチにはAPKと説明・ライセンスだけを含め、既存ゲームのmainやPages設定は変更していません。
