# 仮面葬送 — 異骸の遠征

Godot 4の縦画面オート戦闘RPG、Android用0.1.1です。4人を編成し、遠征で育成と装備を進め、3体の主に挑みます。初回討伐後は融合か複写で新しい個体を迎えます。

[APKをダウンロード（0.1.1）](https://github.com/kemonodot/test-game/raw/refs/heads/apk-masked-requiem-v0.1.1/MaskedRequiem-v0.1.1.apk)

## インストール

1. `MaskedRequiem-v0.1.1.apk`を端末へ保存します。
2. Androidの「ファイル」アプリからAPKを開きます。
3. 必要な場合、設定画面でファイルアプリからのインストールを許可します。
4. インストール後、「仮面葬送」のアイコンをタップします。

Android 7以降、arm64端末、OpenGL ES 3対応が必要です。

## 操作

「仲間」で4人を編成・転職・訓練し、「装備」で遺物を交換します。「通常遠征」で自動周回、「遠征」で主に挑みます。敗北で仲間や遺物は失いません。戦闘速度は1・2・4倍を選べます。保存は自動で、設定から手動保存と初期化もできます。

## 確認範囲

戦闘6,300戦、キャンペーン73項目、GodotネイティブUI49項目、保存・復帰30項目を確認しました。Android APKの生成、Provider設定、ZIP、整列、署名を検証済みです。実機でのインストール・起動・タッチ・性能は未確認です。

0.1.1はProvider識別子の修正版で、ゲームのルールは0.1.0と同じです。以前の版と同じ署名鍵を使っています。
