# 仮面葬送 — 異骸の遠征

Godot 4の縦画面オート戦闘RPG、Android用0.1.2です。4人を編成し、遠征で育成と装備を進め、3体の主に挑みます。初回討伐後は融合か複写で新しい個体を迎えます。

[ZIPをダウンロード（約28MB）](https://github.com/kemonodot/test-game/archive/refs/heads/apk-masked-requiem-v0.1.2.zip)

[APKを直接ダウンロード](https://github.com/kemonodot/test-game/raw/refs/heads/apk-masked-requiem-v0.1.2/MaskedRequiem-v0.1.2.apk)

## インストール

1. ZIPを端末へ保存し、Androidの「ファイル」アプリで展開します。
2. 展開されたフォルダー内の `MaskedRequiem-v0.1.2.apk` を開きます。
3. 必要な場合、設定画面でファイルアプリからのインストールを許可します。
4. インストール後、「仮面葬送」のアイコンをタップします。

Android 7以降、arm64端末、OpenGL ES 3対応が必要です。iPhone/iPadにはAPKをインストールできません。

## 操作

「仲間」で4人を編成・転職・訓練し、「装備」で遺物を交換します。「通常遠征」で自動周回、「遠征」で主に挑みます。敗北で仲間や遺物は失いません。戦闘速度は1・2・4倍を選べます。保存は自動で、設定から手動保存と初期化もできます。

## 変更と確認範囲

0.1.2は日本語フォントを使用文字に絞り、APKを42,388,816バイトから28,265,808バイトへ軽量化しました。ゲームのルール、素材の絵柄、セーブ形式は変えていません。以前の版と同じ署名証明書、同じアプリIDで更新できます。

Godotで692文字の有無・文字と文章の表示幅2,084項目、字形とメトリクス、48行のラスタ比較を確認しました。APKのProvider設定、ZIP、16KB整列、v2/v3署名も検証済みです。Android実機でのインストール・起動・タッチ・性能、端末からのダウンロード完了は未確認です。

ゲーム本体は戦闘6,300戦、キャンペーン73項目、GodotネイティブUI49項目、保存・復帰30項目を確認しています。今回ゲームロジックは変更していないため、これらの大量戦闘テストは再実行していません。

このブランチはAPKと説明・ライセンスのみを含む独立した配布用履歴です。既存ゲームのソース、mainブランチ、Pages設定は変更していません。
