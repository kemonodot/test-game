# アートバイブル：焚き火 × 邪神

**版：0.1 ／ 対象：ステージ1「自宅の庭」**

## 前提と画面

既存のゲーム性は、素材を4×4の火床に置き、12ターンの自動燃焼を見守る儀式。配信先は未定のため、当面はPC・スマートフォン両対応のブラウザゲームを想定する。カメラは火床を真上から見る固定視点。人物や眷属は結果画面・イベント画面で同じピクセルスケールの静止画として見せる。将来の別プラットフォームでも、以下の原画解像度とパレットを共通基準にする。

**絵の核：火の周りだけが存在を許された庭。** 密度の高いピクセルの塊で焦げた物質を描き、光の届かない場所は情報のない黒にする。生き物、薪、供物に同じ描画文法を使い、何が燃料なのか絵だけでは区別させない。露悪や流血よりも、火のそばにあるべきでない形と、暗闇の余白で不穏さをつくる。

## 光と構図

1. **真黒**：火の照射範囲外は `#000000` の塊。木目や庭の輪郭を常時うっすら見せない。
2. **周縁**：火床中心から原画で半径約80〜96 pxの範囲に、最大2段階の暗い面だけを置く。影は火から外へ伸び、同じ方向へわずかに傾く。
3. **供物**：中心から約48 px以内では、火に向く面に橙、背面に灰・緑を配する。形とカードの状態をまず読ませる。
4. **炎と火の芯**：最も明るく、最も細かなクラスターを集中させる。ただしマス境界・残り燃焼数・選択枠を隠さない。

半径は原画での基準であり、描画時は整数倍率で一緒に拡大する。炎の揺れは色段階と輪郭を切り替える。ぼかした光で黒を灰色にしない。火力・濁りは見た目に反映しても、数値と文字で常に確認できるようにする。

## シルエットと材質

- **人物・眷属**：まず黒一色のシルエットで姿勢が読める形にする。許される違和感は、前腕を通常比で約10〜15%長くする、頭の向きの追従を1フレーム遅らせる、重心を片側へ少し寄せる程度。関節や手足の数を曖昧にして操作対象を誤認させない。眷属は小さく、庭の闇の中で火を見ている輪郭とする。
- **焦げた木**：大きな黒い裂け目、火に面した橙の細い縁、灰色の割れ面。木目を全域に散らさず、塊を残す。
- **濡れた石**：暗い灰と緑の面に、火の方向を向く骨色の短い反射を1〜3箇所。白い斑点の全面散布はしない。
- **肉・皮膚・髪**：血赤と緑を暗部へ控えめに混ぜ、木・布と同じ輪郭幅とクラスター密度を使う。露出した損傷を装飾にしない。
- **聖なる物**：骨色の布、印、結び目を黒い地に少数配置。神聖さは整った形と余白で示し、無制限の白い発光にしない。
- **紙・布・骨**：折れ目や繊維は輪郭の近くと火の当たる端に集める。1マスのアイコンでは形を優先する。

## アセットと表示の規格

原画の1ピクセルを全カテゴリで共通の単位とし、ピクセル絵は透過PNG、輪郭を保つ最近傍補間、整数倍率で表示する。CSSピクセルと原画ピクセルは別単位。画面幅が中間サイズのときは整数倍率を選び余白で吸収する。UI文字は読みやすい通常のテキストとして別に描画する。

| 対象 | 原画の固定規格 | 配置・表示 |
|---|---|---|
| 火床 | 4×4マス、1マス32×32 px、全体128×128 px | 中央を固定。占有1〜4マスの矩形に一致させる |
| 素材 | 32×32、64×32、32×64、64×64 pxのいずれか | マス単位。どの形も占有範囲が明確に読める |
| 素材アイコン | 24×24 px、透明余白を含む | シルエットは中心の20×20 px内。画像は整数倍率で表示 |
| 火・煙 | 火床に合わせた32×32 pxのタイル、または128×128 pxの全景 | マスの状態と選択表示を覆わない。透過の黒と真黒を混同しない |
| 防壁・警告・状態アイコン | 16×16 px | 輪郭と内側を最小1原画pxで分け、数字または文字を併記 |
| 人物・眷属の立ち絵 | 96×128 px以内 | 基準となる地面線を共有。顔の向きや手の動きを縮小表示で確認 |
| イベント・結末の一枚絵 | 320×180 px | 火と主要シルエットに密度を集中し、暗い外周は黒のまま |
| ローディング | 128×128 px以内の小さな炉と文字 | 文字は別レイヤー。進行中の表示は動き以外でも分かるようにする |
| 宣伝用アート | 320×180 pxをマスター構図とし、整数倍で書き出し | 薪と供物が混ざる火床を焦点に、タイトル用の黒い余白を確保 |

アイテムやイベント画像は、実際の配置時サイズで識別を確認してから書き出す。異なる解像度の絵を縮小してアイコンに転用しない。素材には名前・タグ・着火コスト・燃焼ターン・火力・濁りなどの必要情報をテキストで併記する。

## UI・入力

焦げ木のパネル、灰の仕切り、骨色の文字、火に照らされた辺を共通の意匠にする。画面の飾りではなく、手元、火床、状態、結果の順に視線を導く。燃焼中・配置済み・選択中は、色に加えて形、文字、枠で区別し、警告や延焼も文字で伝える。文章は火や背景から独立した不透明な地に置く。

本文は実表示で16 CSS px以上、補助文も14 CSS px以上を目安とし、通常文字のコントラスト比は4.5:1以上、重要な非テキスト境界・フォーカス表示は3:1以上を確保する。主要なタップ領域は最低44×44 CSS px。キーボード操作、明瞭なフォーカス、拡大表示、狭い画面での折り返しを維持する。画像のピクセル表現を文字の可読性より優先しない。

## 動き・演出

- 火は4〜6フレームのループを基準に、1フレームあたり120〜200 ms。明度の最大値を毎フレーム点滅させない。
- 煙と火の粉は少数の離散的な塊としてゆっくり移動し、素材や数値に重ねない。
- 人物は長い静止を基本とし、呼吸や指先など1〜2 pxの小さな動きを挟む。視線や頭の向きは意図的に1フレーム遅れる。
- 影は火源の位置に連動し、同じ側へ伸び縮みする。ランダムに方向を変えない。
- `prefers-reduced-motion` では非必須の揺れ・火の粉を止め、状態の変化は文字と静止フレームで伝える。

## 避けること・各バッチの確認

ランダムなピクセルノイズ、均一な全面ディザ、ぼかしによる灰色の暗闇、不揃いなピクセル倍率、画面サイズで消える細部、無意味な流血、突然の脅かし、色だけの状態表示を避ける。既存作品のキャラクター・ロゴ・構図を模倣しない。

各バッチは、①固定パレット・原画サイズ・整数倍率、②真黒と光源方向、③シルエットとマス占有の判読、④実表示サイズの文字・操作領域・コントラスト、⑤静止時と動作時の状態判読、⑥PCとスマートフォン幅を確認する。例外が必要なら新しい個別スタイルを作らず、この文書の基準を更新してから全カテゴリに適用する。
