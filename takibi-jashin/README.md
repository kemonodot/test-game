# 焚き火と、名もなきもの

ステージ1「自宅の庭」のブラウザ向け検証版。HTML / CSS / JavaScriptのみで動作し、追加ライブラリやビルドは不要です。

```sh
cd /workspace/test-game
python3 -m http.server 8000 --bind 127.0.0.1
```

`/takibi-jashin/` を開きます。素材を3択から選び、手元で選択して火床に配置し、「火に委ねる」で1刻進めます。燃えていない素材は選び直し・手元への回収が可能です。素材や部位の効果は画面で確認できます。

灰と解放した素材はブラウザのローカルストレージに保存します。端末・ブラウザが変わると共有されません。進行中のランは保存されません。ステージ1の成功は次の的の解放状態として記録しますが、追加ステージ自体はMVP対象外です。

```sh
node takibi-jashin/tests/game.test.cjs
node takibi-jashin/tools/simulate.cjs 1000
```

自動試走の考え方と結果は [SIMULATION.md](SIMULATION.md)、視覚方針は [ART_BIBLE.md](ART_BIBLE.md) を参照。実装上、基礎火は火床の中央2列に接し、名指し要求は燃焼完了で達成、訪問者の交換対象は手元の先頭です。耳の効果は要求を1刻早く知らせ、通常と同じ期限にします。数値、カード、イベント、イラストはすべて検証用です。
