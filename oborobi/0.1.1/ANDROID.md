# Androidで遊ぶ

配布ファイルは **Oborobi-Android.apk / 0.1.1**。素材・日本語フォント・音を含む単体アプリです。スマホにGodotや開発ツールを入れる必要はありません。

## インストール

1. 提出されたAPKをAndroid端末へダウンロードします。PCに保存した場合は、USBやファイル転送でスマホへコピーしてください。
2. 「ファイル」アプリのダウンロードフォルダで `Oborobi-Android.apk` を開きます。
3. インストール元の許可を求められた場合は、そのブラウザ／ファイルアプリについて「この提供元を許可」を有効にし、戻って「インストール」を押します。
4. ホーム画面の **「朧火」** を開き、「境内へ入る」をタップします。横画面で起動します。

Android 7.0（API 24）以降、OpenGL ES 3.0対応の端末が対象です。ARM 64bit・ARM 32bit、検証用のx86_64を同じAPKに含めています。Google Play経由の配布ではなく、プロトタイプ用の署名を付けた直接インストール版です。

## 片手での操作

- 戦場の空いている場所に指を置き、そのまま移動したい方向へドラッグ。指を離すと停止します。
- 刀と青い魂火は自動。敵が落とす魂へ近づくと経験値を吸収します。
- レベルアップの3枚から1枚をタップ。選んでいる間は戦闘が停止します。
- 右上の **II** で停止、「戦闘へ戻る」で再開。音のボタンで消音できます。
- Androidの「戻る」は戦闘中の停止・再開に使えます。強化選択中はカードを保持します。開始・結果画面で押すと終了します。
- 別のアプリへ切り替えると停止します。戻ったら再開ボタンを押してください。
- 180秒生存でクリア。HP0で死亡し、結果画面から再挑戦できます。

16:9以外の画面では戦場の比率を保ち、余白を付けます。ゲームはネット接続やアカウント登録を必要としません。セーブはなく、OSに終了された場合は新しいランになります。

## 開発者向け

Godot 4.6.3、Android SDK 36、Build Tools 36.0.0で書き出しています。Compatibility描画、60fps上限、横画面、ETC2/ASTCインポート、拡大した停止・音ボタンを設定しています。60fpsは上限設定で、実機の性能保証ではありません。

`export_presets.cfg` の「Android」からAPKを作成できます。Godotのエディター設定でJava、SDK、署名鍵の保存先を設定してください。配布の試作鍵はクラウドのツールチェーン側に保持し、ソースZIPへ含めていません。Play Store用の署名・AAB・公開手続きはこの提出物の範囲に含みません。

このクラウド環境の再ビルド:

```sh
python3 /workspace/toolchains/setup-android.py
bash /workspace/toolchains/build-oborobi-android.sh
```

最終ファイルの署名・内容・操作の検証記録は [TEST_RESULTS.md](TEST_RESULTS.md) に記載しています。物理的なスマホでのFPS・発熱・端末ごとのジェスチャー干渉は未検証です。

クラウドの仮想端末はCPUの仮想化支援が使えず、Androidのパッケージ管理サービスが安定しないため、この環境でのAPK起動確認は完了していません。署名・パッケージ内容、Godot上での戦闘・タッチ・戻る・背景移行は検証しています。
