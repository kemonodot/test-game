# 朧火 — Android 0.4.0

Godot 4.6.3の3分サバイバル。スワイプで鬼面と壁を渡り、敵への接近で溜めた鎖火を次の移動攻撃「鎖葬」に変えます。被弾や4秒の途切れで溜めた力を失います。

[ダウンロードページ](https://kemonodot.github.io/test-game/oborobi/) / [Android APK](0.4.0/Oborobi-Android.apk) / [Godotプロジェクト一式](0.4.0/OborobiGodot.zip)

- 敵のそばを高速で突破すると鎖火＋1、鬼面到着で＋2。
- 3つで次の鎖接続が金色の広い斬撃に。追加のボタンはありません。
- 通常敵は鎖を遮らず、高速移動を止めません。鎖移動全体が無敵ではありません。
- 炎の轍・連鎖雷・周回刃・花の衝撃波も修得できます。

[操作・導入](0.4.0/ANDROID.md) / [検証結果](0.4.0/TEST_RESULTS.md) / [実際の戦闘画面](0.4.0/captures/17-chain-burst-middle.png)

Android 7.0以降、OpenGL ES 3.0。0.3.0までと同じ署名で上書き更新できる構成です。Godot上で130項目・シナリオ、3分の通し実行、実描画、署名を確認。0.4.0のAndroid実機起動・性能は未検証です。動画は録画していません。
