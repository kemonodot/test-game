# 朧火 — Android 0.5.0

Godot 4.6.3の巨大ボス1体の検証版。開始から「骸綱 / 鎖を喰らう鬼」に挑み、予告を鎖で避けて金色の環へ反撃します。

[ダウンロードページ](https://kemonodot.github.io/test-game/oborobi/) / [Android APK](0.5.0/Oborobi-Android.apk) / [Godotプロジェクト一式](0.5.0/OborobiGodot.zip)

- スワイプで鎖移動。ボスの環・壁へ接続し、小さい敵は高速移動を遮りません。
- 予告の中から鎖で回避すると鎖火＋1、直後の指定の環への返し鎖で＋2。密集した敵を通るだけでは増えません。
- 鎖火3で次の接続が金色の広い斬撃。被弾や7秒の途切れで力を失います。
- 右下から手動大技：鎖は高速移動、炎は回復と抑制、刀は防御崩し。別の指でも使用できます。
- ボスHP0で討伐完了。成長3択、落命、再挑戦まで遊べます。複数ボスへの遷移はありません。
