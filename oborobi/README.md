# 朧火 — スワイプと4つの術 Android検証版 0.3.0

ダウンロードページ: https://kemonodot.github.io/test-game/oborobi/

`0.3.0/Oborobi-Android.apk` はGodot 4.6.3製のAndroidアプリです。
Android 7.0以降・OpenGL ES 3.0対応端末向け。ファイルアプリでAPKを開き、
インストール後にアプリ「朧火」を起動してください。

進みたい方向へ短くスワイプすると、指を離す前に一本の鎖を射出します。移動中も次のスワイプで方向変更。接続先は大きい鬼面・石垣・外周で、小さい敵は鎖や高速移動を止めません。短いタップで解除すると慣性で滑走します。

新しい術は残火の轍・雷渡り・三日月の輪・彼岸の花。炎の道、連鎖雷、周回する刃、花の衝撃波を追加します。最初のレベルアップで新しい術の3択を出します。

旧版0.1.1 / 0.2.0と同じ署名・アプリIDで上書き更新できる構成です。以前の配布ファイルも各バージョンのフォルダに残しています。

`0.3.0/OborobiGodot.zip` に実行可能なGodotプロジェクト、READMEとテスト記録を含みます。
`0.3.0/ANDROID.md` に導入・操作手順、`0.3.0/SHA256SUMS.txt` に配布ファイルのSHA256を記録しています。
新しいスクリーンショットはLinux上のGodotで実際に描画した記録。今回は動画を録画していません。

署名・APK内容・Godot上の鎖と衝突36項目・新スキル23項目・戦闘31項目・タッチと中断12シナリオは検証済みです。
Android上での起動・実機性能は未検証です。試作鍵はリポジトリに含めていません。

この環境ではGitHub Releaseの添付先 `uploads.github.com` が通信制限で利用できないため、
配布ファイルをGitHub Pagesで提供しています。ゲーム本体はネイティブのGodotアプリです。
