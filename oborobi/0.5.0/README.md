# 朧火 — OBOROBI 0.5.0

Godot 4.6.3製、Android横画面向けの**巨大ボス1体と戦う検証版**。開始から「骸綱 / 鎖を喰らう鬼」に挑みます。鎖で予告攻撃を避け、隙へ戻る反撃と、手動で使う鎖・炎・刀の大技を試せます。

ダウンロード: https://kemonodot.github.io/test-game/oborobi/

## 起動

AndroidではAPKをインストールし、「朧火」→「巨鬼に挑む」。スマホにGodotは不要です。[ANDROID.md](ANDROID.md) に導入手順があります。以前の0.1.1〜0.4.0と同じアプリID・署名で上書き更新できる構成です。

ソースZIPを展開し、**Godot 4.6.3 Standard**で `project.godot` をインポートしてF5。PNG・WAV・日本語フォント・ライセンスを同梱しています。通常の実行にPythonや外部プラグイン、通信は不要です。

```sh
godot --headless --editor --import --path /path/to/OborobiGodot
godot --path /path/to/OborobiGodot
```

## 操作と勝利条件

- **進みたい方向へ短くスワイプ。** 指を離す前に鎖が発射されます。一度離して次のスワイプをすると、移動中もつなぎ直せます。
- **短くタップで鎖を解除。** 慣性で少し滑走します。
- 接続先はボスの3つの環、中央の石垣、外周。小さい取り巻きには接続せず、高速移動中は突破できます。巨大なボスの身体と壁は進路を止めます。
- **右下の3ボタンで大技。** 最初から使用可能で、それぞれ別の再使用待ちがあります。移動の指を置いたまま、別の指でも押せます。
- 刀・魂火・修得した術は自動発動。魂を拾うとレベルアップし、3択をタップして再開します。
- 右上の「II」、Androidの戻るで一時停止。「音 / 静」で消音。別アプリへ移ると停止し、戻った後は再開操作を待ちます。
- **ボスのHPを0にすると、崩壊演出の後に討伐完了。** 時間経過によるクリアはありません。HP0で落命し、結果から再挑戦できます。

PCではマウスの短いドラッグで鎖移動。Spaceで射出・解除、WASD / 方向キーで補助歩行、**Q / E / R**で鎖・炎・刀の大技、P / Escapeで停止できます。

## 回避から返し鎖へ

ボスは「薙ぎ払い」「鎖の貫き」「踏み砕き」の3種類を予告し、攻撃後に環が1つ金色になります。半分まで削ると予告と隙が短くなります。

| 行動 | 報酬・損失 |
| --- | --- |
| 予告の中から鎖を発射し、実際に移動して攻撃時に範囲外へ逃れる | 鎖火＋1 |
| 回避直後の隙に、金色の環へ鎖で戻る | 鎖火＋2、強い反撃、経験値の魂 |
| 鎖火3で次の鎖が接続する | 金色の広い移動斬撃「鎖葬」 |
| 被弾する | 鎖火を全て失い、鎖葬も終了 |
| 接続・獲得が7秒途切れる | 溜めた鎖火が消える |

**敵の近くを通るだけ、開いていない環への到着、予告外からの発射では溜まりません。** 予告の中から発射しても、移動が足りない場合や、途中で被弾した場合は回避報酬がありません。回復でHPを戻しても、その攻撃の失敗は取り消されません。1回の予告に対する回避・返し鎖の報酬は各1回です。

鎖移動は常時無敵ではありません。短い接触保護がある間も、ボスの予告攻撃が着弾すればダメージを受けます。返し鎖の隙は約3秒。退避先だけでなく、戻れる距離も考える攻防を検証します。停止・強化画面では鎖火の保持時間も止まります。

## 手動大技3種

いずれも画面全体へ攻撃し、石垣を越えて届きます。演出は約1秒、戦術効果は5秒。通常の刀・魂火・鎖葬は壁で遮られます。

| 系統・名前 | 見た目 | 使うメリット | 再使用 |
| --- | --- | --- | --- |
| 鎖 / 天鎖解放 | 戦場の周囲から金色の鎖が集結 | 5秒間、鎖の加速・最高速度と歩行速度が大幅アップ。次の鎖をすぐ出せる | 20秒 |
| 炎 / 蒼炎還魂 | 蒼い魂火の波が戦場へ広がる | HP28回復。5秒間、取り巻きの接触攻撃を抑制し、ボスの予告進行を遅くする。ボス攻撃の被ダメージ半減と継続燃焼 | 26秒 |
| 刀 / 天断ち | 画面を交差して切り裂く3本の斬撃 | 強い一撃と5秒間の防御崩し。全ての環が開き、続く攻撃も通る | 30秒 |

刀で全環を開いても、鎖火＋2の返し鎖は「予告を鎖で避けた後の指定の環」への到着だけです。回復・高速移動・攻撃機会のどれを必要としているかで使い分けられます。

## 成長と演出

返し鎖と少数の取り巻きから魂を回収し、3択で成長します。初回は新しい術を提示。自動発動する「残火の轍」「雷渡り」「三日月の輪」「彼岸の花」と、従来の数値強化を合わせて14種類あります。取り巻きは同時8体までです。

小さい敵は敵色のピクセル破片に砕け、強い攻撃では飛散が増します。ボス討伐時は本体のドット絵が8×8ピクセルの断片へ分かれて崩壊。命中フラッシュ、火花、短いヒットストップ、控えめな揺れ、経験値の吸収、成長・落命演出も実行します。

## ファイル構成と調整箇所

```text
OborobiGodot/
├── project.godot / main.tscn / export_presets.cfg
├── scripts/
│   ├── game.gd            入力・音・停止・遷移
│   ├── combat.gd          戦闘・経験値・成長・HP
│   ├── boss.gd            巨鬼・予告・隙・返し鎖
│   ├── grapple.gd         鎖・巻き取り・慣性・鎖火・鎖葬
│   ├── ultimates.gd       手動大技3種と再使用時間
│   ├── arena_geometry.gd  壁・外周・衝突
│   ├── skills.gd          自動発動する4つの術
│   ├── battlefield.gd     ピクセル描画とVFX
│   └── hud.gd             開始・HUD・3択・停止・結果
├── assets/                素材・音・日本語フォント・ライセンス
├── tests/                 戦闘・入力・回避反撃・描画の検証
├── captures/              今回の実画面と検証ログ
├── tools/                 任意の素材再生成
└── README.md / ANDROID.md / TEST_RESULTS.md
```

ボスのHP・攻撃時間は `boss.gd`、鎖火の保持や鎖速度は `grapple.gd`、大技は `ultimates.gd`、入力の長さは `game.gd` の `SWIPE_DISTANCE`、見た目は `battlefield.gd` とPNGが入口です。素材再生成だけはPython / Pillow / fontToolsと元のNotoフォントが必要です。

## 注意点と今回検証すること

- 複数ボスへ進む前の、**巨鬼1体の戦闘検証**です。回避から反撃へ戻りたくなるか、3つの大技を場面で使い分けるかを試します。
- Android 7.0以降、OpenGL ES 3.0、横画面、60fps上限。0.5.0 / version code 6。Android実機での起動・操作感・FPS・発熱は未検証です。
- 戦場640×360をNearest拡大し、UI1280×720を重ねます。画面比率を維持するため、端末によって余白が出ます。
- 破片520個、魂160個、弾24個、大技の演出3個に上限。ボスの崩壊は固定256断片。キャラや破片ごとのノードは作りません。
- 鎖は一本で、平面移動です。振り子、二本の鎖、壁への巻き付きはありません。中央の石垣と外周に衝突し、鳥居・灯籠は装飾です。
- セーブ・通信・オフライン進行・ストーリー・マップ・ショップ・装備管理はありません。OSに終了された場合は最初からです。

ピクセル素材・音はオリジナル。NotoフォントとGodotのライセンスは `assets/fonts/LICENSE.txt`、`assets/licenses/Godot-LICENSE.txt` を参照してください。
