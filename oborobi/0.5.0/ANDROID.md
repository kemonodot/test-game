# Androidで遊ぶ — 0.5.0

**朧火：巨大ボス1体の検証版。** スワイプでボスの予告を避け、金色の環へ返し鎖。鎖・炎・刀の大技は右下から任意に発動できます。

ダウンロード: https://kemonodot.github.io/test-game/oborobi/

## インストール・更新

1. Chromeなどでページを開き、0.5.0のAPKを保存します。アプリ内ブラウザで保存できない場合はChromeで開いてください。
2. 「ファイル」アプリのダウンロードフォルダで `Oborobi-Android.apk` を開きます。
3. 提供元の許可を求められた場合は、そのブラウザ／ファイルアプリについて許可し、戻って「インストール」を押します。
4. アプリ「朧火」→「巨鬼に挑む」をタップします。

0.1.1 / 0.2.0 / 0.3.0 / 0.4.0と同じアプリID・署名鍵で、version codeは6。上書き更新できる構成です。スマホへのGodot導入は不要です。

Android 7.0（API 24）以降、OpenGL ES 3.0対応端末向け。ARM 64bit・ARM 32bit・x86_64を含みます。プロトタイプ署名の直接インストール版です。

## 操作

- **短いスワイプで鎖を射出。** 指が動いた時点で発射されます。一度離し、次のスワイプで方向を変えてつなぎ直せます。
- **短いタップで鎖を解除。** 勢いは少し残ります。
- 接続先は巨大ボスの環3つ・石垣・外周。小さい敵は接続対象にならず、高速移動を遮りません。ボスの身体と壁には衝突します。
- **右下の「鎖」「炎」「刀」をタップして大技。** 開始から使用可能で、移動中は別の指でも押せます。待ち時間は各ボタンに表示します。
- 鎖は5秒の高速移動（再使用20秒）、炎はHP28回復・5秒の攻撃抑制（26秒）、刀は5秒の防御崩し・全環を開く（30秒）。
- 刀・魂火・修得した術は自動発動。魂を拾って成長し、3択をタップします。
- ボスHP0で討伐、HP0で落命。時間でのクリアはなく、結果から再挑戦できます。
- 右上の「II」またはAndroidの戻るで停止・再開。「音 / 静」で消音。別アプリへ移った後は手動で再開してください。
- 開始・結果画面で戻るを押すと終了します。通信や登録は不要で、セーブはありません。

## 鎖火を溜める手順

1. 赤い攻撃予告の**中から**鎖で十分に移動し、攻撃が来るまでに予告の外へ出る：＋1。
2. 直後の隙に、金色に光った環へ鎖で戻る：＋2と反撃・経験値。
3. 3つ溜まったら、次の鎖が接続した時に広い金色の移動斬撃「鎖葬」。

敵のそばを通るだけでは溜まりません。被弾で全て失い、接続や獲得が7秒途切れた場合も消えます。停止・強化選択中は時間を保持します。移動中も予告攻撃が当たれば被弾するため、常時無敵ではありません。

## 開発・確認状況

Godot 4.6.3、SDK 36 / Build Tools 36.0.0、Compatibility描画。60fpsは上限設定で、実機FPSを保証するものではありません。

```sh
python3 /workspace/toolchains/setup-android.py
bash /workspace/toolchains/build-oborobi-android.sh
```

他のPCではGodotのJava・Android SDK・署名鍵を設定し、同梱の `export_presets.cfg` から書き出します。クラウドの試作署名鍵は配布ZIPに含めていません。

Godotの入力・戦闘・実描画とAPKの検証は [TEST_RESULTS.md](TEST_RESULTS.md)。**0.5.0のAndroid実機での起動・操作感・FPS・発熱は未検証です。** クラウドには安定して実行できるAndroid仮想端末がありません。
