# 検証結果 — スワイプと術の0.3.0

2026-10-10 / Godot 4.6.3.stable.official / Debian Linux。

**鎖36項目・術23項目・戦闘31項目・ネイティブ入力12シナリオが合格、各ランナーは終了コード0。** スワイプ中の即射出、通常敵を対象にしない鎖、群れの突破、4種類の新しい攻撃を検証しました。Android実機上の0.3.0の起動・性能は未検証です。

## 操作と鎖

- [入力ログ](captures/android/touch-test.log): 実際のGodot入力系へScreenTouch / ScreenDragを送り、GUI・戦場を操作。
- 指を離す前に射出し、同じスワイプの続きや指を離した時に二重射出しないこと。
- 移動中の次のスワイプで速度を保って方向変更。短いタップによる解除・滑走。
- 小さい入力をキャンセルした場合の誤射防止、射出済みの入力をキャンセルしても二重射出しないこと。
- 開始・停止・再開・3択、Androidの戻る通知、アプリ背景移行と復帰後の停止維持。
- [鎖ログ](captures/android/grapple-test.log): 36 / 36。壁・外周・角・高速の経路全体の衝突判定、鬼面への接続、死亡した接続先の解除、追跡の回り込み、連鎖。
- 通常敵は接続先にならず、飛行中の鎖も遮らないこと。通常敵が生き残っても高速の鎖移動を止めず、硬い鬼面は止めること。

## 新しい術

[術ログ](captures/android/skills-test.log): **23 / 23合格**。

- 4種類とも基礎ステータスを変えず、新しい攻撃を追加すること。
- 初回の3択に新しい術が出ること、取得済みの術を重複提示しないこと。
- 未修得の術が勝手に発動しないこと。
- 連鎖雷が表示した3体だけを攻撃し、石垣の向こうを攻撃しないこと。
- 移動が蒼い炎の実際のダメージ地点を作り、ダメージ間隔・寿命・28地点の上限を守ること。
- 3枚の刃が実際に接触判定を持ち、同じ敵への連続ヒットを抑え、壁の向こうを切らないこと。
- 花の波が見た目の半径に沿って広がり、遠い敵に先にダメージを与えず、同じ波で一体を複数回攻撃しないこと。
- 波の射線遮断、短い効果18個の上限、強化選択中の停止。

## 残る検証

0.3.0のAndroid実機での起動・操作感・FPS・発熱・画面端のシステムジェスチャーとの干渉は未検証です。クラウドには使用可能なKVMがなく、CPUのみの仮想端末ではAndroidのパッケージ管理が安定しません。Linuxのソフトウェア描画をAndroidの性能測定として扱っていません。

新しい術の取得順、連続スワイプの方向転換、混雑時の突破、炎の道を使う立ち回りをスマホで試せる版です。鎖は一本で、振り子や壁への巻き付きはありません。
