# Androidで遊ぶ — 0.3.0

**Oborobi-Android.apk** は、スワイプで鎖移動する「朧火」の更新版です。大きい鬼面だけに接続し、小さい敵の群れを突破できます。4種類の新しい術も追加しています。

ダウンロード: https://kemonodot.github.io/test-game/oborobi/

## インストール・更新

1. ページをChromeなどで開き、0.3.0のAPKをダウンロードします。
2. 「ファイル」アプリのダウンロードフォルダで `Oborobi-Android.apk` を開きます。
3. 提供元の許可を求められた場合は、そのブラウザ／ファイルアプリについて許可し、戻って「インストール」を押します。
4. アプリ「朧火」を開き、「境内へ入る」をタップします。

0.1.1 / 0.2.0と同じアプリID・署名鍵で、version codeを4へ上げています。以前の「朧火」に上書き更新できる構成です。Godotや開発ツールをスマホへ入れる必要はありません。

Android 7.0（API 24）以降、OpenGL ES 3.0対応端末向け。ARM 64bit・ARM 32bit・x86_64を含みます。Google Play経由ではなく、プロトタイプ署名による直接インストール版です。

## 操作

- **進みたい方向へ短くスワイプ。** 指を離す前に鎖を射出します。長く狙い続ける必要はありません。
- 一度指を離し、続けてスワイプすると次の鎖へ。移動中も方向を変えられ、速度が残ります。
- **短いタップで鎖を解除。** 慣性で少し滑走します。
- 接続先は大きい鬼面・石垣・外周。鬼面の頭上に金色の印があります。小さい敵は鎖を遮らず、高速の鎖移動を止めません。停止時の接触ではダメージを受けます。
- 刀・魂火・修得した術は自動。魂を集めてレベルアップし、3択をタップして強化します。最初の3択は新しい術です。
- 新しい術は「残火の轍」「雷渡り」「三日月の輪」「彼岸の花」。炎の道、連鎖する雷、周回する刃、花びらの衝撃波です。
- 右上の「II」またはAndroidの戻るで一時停止・再開。「音 / 静」で消音。
- 別のアプリへ移ると停止します。戻ったら手動で再開してください。開始・結果画面で戻るを押すと終了します。
- 180秒生存でクリア。HP0で落命。どちらも結果画面から再挑戦できます。

ゲームは通信・アカウント登録不要。セーブはなく、OSに終了された場合は新しいランになります。

## 開発者向け

Godot 4.6.3、Android SDK 36、Build Tools 36.0.0でエクスポートしています。Compatibility描画、横画面、60fps上限。これは上限設定で、実機のFPS保証ではありません。

ソースの `export_presets.cfg` にAndroidプリセットがあります。Godotの設定でJava、SDK、署名鍵を指定して書き出してください。試作の署名鍵はクラウドのツールチェーン側に保持し、配布ソースへ含めていません。

このクラウドでの再ビルド:

```sh
python3 /workspace/toolchains/setup-android.py
bash /workspace/toolchains/build-oborobi-android.sh
```

[TEST_RESULTS.md](TEST_RESULTS.md) に検証結果があります。署名・APK内容・Godot上のスワイプ入力と戦闘は検証済み。**0.3.0のAndroid実機での起動・操作感・FPS・発熱は未検証です。** クラウドのCPUのみの仮想端末ではAndroidのパッケージ管理が安定せず、実行確認に使える環境がありません。
