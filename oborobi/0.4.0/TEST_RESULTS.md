## 新しいリスクと報酬

[鎖火・鎖葬ログ](captures/android/chain-risk-test.log): 28 / 28。

- 安全な壁移動、停止、歩行では溜まらず、高速の接近で溜まること。
- 接近を報酬にしても、架空の命中や無敵を付与しないこと。
- 通常の強襲で倒した敵からも報酬を得られること。
- 同じ敵への往復や同じ鬼面への再接続で報酬を繰り返し得られないこと。
- 実際の鬼面到着で大きい報酬を得ること。
- 3つの鎖火が基礎ステータスを変えず、次の接続まで待機すること。
- 途中で死んだ接続先では満タンの力を消費しないこと。
- 金色の強攻撃が通常の身体接触より広い範囲を攻撃し、鬼面も強く砕くこと。
- 発動中に方向を変えても同じ敵へ多重ヒットせず、攻撃と残像が短時間で終了すること。
- 被弾でHPと鎖火を失い、発動中の攻撃も終わること。通常の被弾後の保護時間を維持すること。
- 4秒の途切れによる消失、新しい接続による保持時間の更新、停止中の保持。
- 石垣で止まる移動から壁の向こうの敵を攻撃・回収しないこと。
