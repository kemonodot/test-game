# 朧火 — OBOROBI 0.4.0

Godot 4.6.3製、スマホ横画面向けの3分サバイバル。**敵へ飛び込んで鎖火を溜め、次の鎖移動で金色の広い斬撃「鎖葬」を放つ検証版**です。スワイプ操作、鬼面と壁への接続、4種類の術を引き続き遊べます。

ダウンロード: https://kemonodot.github.io/test-game/oborobi/

## 起動

Androidでは `Oborobi-Android.apk` をインストールして「朧火」を開きます。スマホにGodotは不要です。詳しい導入は [ANDROID.md](ANDROID.md)。0.1.1 / 0.2.0 / 0.3.0と同じ署名・アプリIDで、上書き更新できる構成です。

ソースではZIPを展開し、**Godot 4.6.3 Standard**で `project.godot` をインポートしてF5。素材・日本語フォント・音・ライセンスを同梱しており、外部プラグイン・通信・Pythonは通常の実行に不要です。

```sh
godot --headless --editor --import --path /path/to/OborobiGodot
godot --path /path/to/OborobiGodot
```

## 操作

- **進みたい方向へ短くスワイプ。** 指が動いた時点で鎖を射出します。狙いを保持したり、指を離すタイミングを合わせる必要はありません。
- **移動中も次のスワイプへ。** 新しい方向へ鎖をつなぎ直し、飛行中も慣性を保ちます。同じ指を動かし続けるだけでは連射しません。一度離して、次のスワイプをしてください。
- **短くタップすると鎖を解除。** 速度が残って少し滑走します。
- 接続できるのは**大きい鬼面の敵・中央の石垣・外周**。鬼面には頭上に金色の接続印があります。小さい足軽は鎖を遮らず、鎖で高速移動している間は進路を止めません。立ち止まると敵との接触でダメージを受けます。
- 刀と青い魂火、修得した術は自動で発動します。高速で敵に接触すると強襲斬撃。硬い鬼面や石垣は進路を止めることがあります。
- 魂を集めるとレベルアップ。3択をタップして戦闘を再開。最初のレベルアップでは新しい術を3択に出します。
- 右上の「II」またはAndroidの戻るで停止・再開。アプリを離れると停止し、戻った後は再開操作を待ちます。「音 / 静」で消音。
- 180秒生存でクリア。HP0で落命。どちらも再挑戦できます。

PCではマウスの短いドラッグで同じスワイプ操作。Spaceで射出・解除、WASD / 方向キーで補助歩行、P / Escapeで一時停止できます。

## 鎖移動のリスクと報酬

| 行動 | 結果 |
| --- | --- |
| 鎖で敵のそばを高速で抜ける | 鎖火 +1 |
| 鬼面の手前まで巻き取って到着する | 鎖火 +2 |
| 鎖火3で、次の鎖を接続する | 溜めた力を使い、金色の広い斬撃「鎖葬」で切り抜ける |
| 被弾する | 鎖火をすべて失い、発動中の鎖葬も終了 |
| 鎖をつながず4秒経つ | 溜めた鎖火が消える |

近接突破・鬼面到着は、それぞれ同じ敵から一度だけ得られます。安全な壁移動、歩行、立ち止まった自動攻撃では溜まりません。新しい接続や報酬獲得で保持時間を更新します。停止・強化選択中は保持時間も止まります。接続先が射出中に死んだ場合、満タンの力は消費しません。

鎖葬は最初から使える、短時間の移動攻撃です。進路の広い範囲を切り、硬い鬼面も強く砕きます。壁の向こうには届かず、一回の鎖葬で同じ敵を何度も攻撃しません。基礎の刀・魂火の能力値は変わりません。HUDに鎖火3つ・保持時間・消失理由、満タン時には主人公の頭上にも印を表示。結果には鎖葬回数と危険突破回数を記録します。

**鎖移動中すべてが無敵ではありません。** 通常の突破や鬼面到着にある短い保護は継続していますが、出だし・減速・停止時などの接触では被弾する場合があります。敵の近くで止まる危険を負い、次の鎖で報酬を使う立ち回りを試せます。

## 4種類の術

いずれも一度の修得で新しい攻撃を追加します。基礎の移動速度・刀威力などを上げる強化ではありません。

| 術 | 見た目と攻撃 | 移動との関係 |
| --- | --- | --- |
| 残火の轍 | 通った道に短い蒼い炎が残り、敵を焼く | 連続で鎖移動すると炎の道が伸びる |
| 雷渡り | 白いジグザグの雷が近くの3体をつなぐ | 群れのそばを横切りながら発動 |
| 三日月の輪 | 3枚の刃が周囲を巡り、軌跡に触れた敵を切る | 移動しながら周囲の敵を削る |
| 彼岸の花 | 8枚の花びら状の斬撃が広がる衝撃波 | 定期的に周囲を薙ぎ、離れた位置へ残る |

術は重複修得せず、取得済みの術は選択肢から外れます。従来の数値強化10種類も残しており、合計14種類。初回以降も未修得の術を優先して提示します。連続接続は「連鎖」で表示し、結果に今回の最大連鎖と術の修得数を表示します。

## 構成

```text
OborobiGodot/
├── project.godot / main.tscn / export_presets.cfg
├── scripts/
│   ├── game.gd            スワイプ入力・音・停止・画面遷移
│   ├── grapple.gd         鬼面と壁への接続・巻き取り・慣性・鎖火・鎖葬
│   ├── arena_geometry.gd  石垣・外周・経路の衝突判定
│   ├── combat.gd          追跡・自動攻撃・経験値・3択・リザルト
│   ├── skills.gd          新しい4種類の術と効果の上限
│   ├── battlefield.gd     ピクセルの背景・キャラ・動くVFX
│   └── hud.gd             HUD・開始・3択・停止・結果
├── assets/                PNG・WAV・日本語フォント・ライセンス
├── tests/                 入力・戦闘・鎖・術・実描画の検証
├── captures/              今回のスクリーンショットと検証ログ
└── tools/                 任意の素材・音・フォント再生成スクリプト
```

鎖の報酬は `grapple.gd` の定数で調整できます。鎖火3、保持4秒、接近速度180、鎖葬0.7秒・幅の半径32・威力90が初期値です。

調整の入口は、スワイプの長さが `game.gd` の `SWIPE_DISTANCE`、鎖の速度・射出が `grapple.gd`、地形が `arena_geometry.gd`、術の挙動が `skills.gd`、VFXの形が `battlefield.gd` です。

## 制約と注意点

- Android 7.0以降、OpenGL ES 3.0対応端末向け。横画面、60fps上限、通信権限なし。版番号0.4.0、version code 5。物理端末での0.4.0の起動・FPS・発熱は未検証です。
- 描画は640×360の戦場をNearestで拡大し、1280×720の読みやすいUIを重ねています。16:9以外では画面比率を維持します。
- 敵110体、破片520個、魂160個、弾24個。新しい術は炎28地点、短い効果18個、鎖葬の残像24本まで。キャラ・破片・鎖の節ごとのノードは生成しません。
- 鎖は一本。振り子・二本の鎖・壁への巻き付きはありません。鳥居・灯籠は装飾、中央の石垣と外周が衝突する壁です。
- 低FPSでは進行が遅くなる場合があります。スワイプ感度、システムジェスチャーとの干渉、負荷の高い場面の実機調整は今後の検証項目です。
- セーブ・通信・オフライン進行・ワールドマップ・ストーリー・ショップ・装備管理はありません。OSに終了された場合は最初からです。

ピクセル素材・音はオリジナル、日本語フォントはNoto Sans CJKのサブセットです。ライセンスは `assets/fonts/LICENSE.txt` と `assets/licenses/Godot-LICENSE.txt` を参照してください。素材再生成だけはPython / Pillow / fontToolsと元のNotoフォントが必要です。
