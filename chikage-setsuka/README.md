# 異常処理室 — セツカとチカゲ

**ふたりの育て方が、同じ夜の回り方を変える。**

固定キャラクター2人の自動進行・ビルド選択RPG。通常CASE9件を処理し、10件目のボス《夜を喰う観測者》へ向かう、最後まで遊べるブラウザゲームのMVPです。

HTML / CSS / JavaScriptのみ。ビルド、外部ライブラリ、外部フォント、アカウント、通信先、インストールが必要なゲーム依存関係はありません。

## 起動

### スマホから遊ぶ（GitHub Pages）

公開URL: **https://kemonodot.github.io/test-game/chikage-setsuka/**

iPhoneのSafari、AndroidのChromeなどで開けば、そのまま遊べます。スマホにPythonやZIP展開は不要です。必要ならブラウザの「ホーム画面に追加」からショートカットを作成できます。ホーム画面からの起動でも保存・オフライン進行はありません。

この公開リポジトリでは、GitHub Pagesが **Deploy from a branch / main / / (root)** で有効です。ゲームは `chikage-setsuka/` に配置し、トップページのFLASH / PARRYと共存しています。`.nojekyll`で静的ファイルをそのまま配信します。

更新時は、動作確認済みの変更を `main` にコミットしてpushします。Pagesの設定変更やビルドツールは不要です。

### パソコンでローカル起動

フォルダ構成を保ったまま **`index.html` をブラウザで開く**と遊べます。スクリプトは通常の`defer`読み込みで、ES modulesや`fetch`を使わないため、一般的なブラウザでファイルから起動できる構成です。

管理されたブラウザなど、`file://`が制限されている環境では、次のローカルHTTP起動を使ってください。Pythonはこの任意の配信用途だけに使い、ゲーム自体の依存関係ではありません。

```sh
cd test-game/chikage-setsuka
python3 -m http.server 8000 --bind 127.0.0.1
```

同じマシンのブラウザで `http://127.0.0.1:8000` を開きます。終了はターミナルで `Ctrl+C`。ポートが使用中なら、コマンドとブラウザの両方を8001などに変更してください。

クラウド検証では管理ブラウザが`file://`を拒否したため、ローカルHTTPで動作確認しています。

## 遊び方

1. **「夜勤を開始する」**を押し、セツカの最初の育成方針を選ぶ。
2. ふたりが自動で処理・解析を進める。最初のCASEの処理50%で、チカゲの育成方針を選ぶ。
3. 以降は各CASEの**処理50%**と**通常CASE解決後**に、提示される3枚からひとつ選ぶ。クリアまでに合計20回選択できる。
4. **BUILD**で現在の傾向・実効性能・主要効果・連携を確認。**ARCHIVE**で遭遇した怪異と9種の連携条件を調べる。
5. **処理100%**でCASE解決。解析100%は必須ではないが、解析が進むほどDATAが増え、弱点看破で火力が上がる。完全解析は危険の上昇も抑える。
6. **危険100%**で緊急撤退。次のCASEに進むと、危険は前CASEの55%＋6pt（最低10）に下がる。
7. 10件目のボスを倒すとクリア。クリア・撤退の両方にリザルトがあり、**「別のビルドで再挑戦」**からやり直せる。

強化に資源の支払いは不要です。異物は回収成果、DATAは研究と評価の指標です。DATAの研究評価が60 / 150 / 300に達すると、看破が早まり、危険制御も向上します。《解剖ログ》は研究評価を増幅します。

右上の **1× / 2×** で速度を切り替えられます。一時停止、オーバーレイ表示中、タブ非表示中は進行しません。

## まず試したい3つのビルド

| 組み合わせ | 連携 | 回り方の違い |
| --- | --- | --- |
| 回収セツカ × 解析チカゲ | 完全解剖 | 捕獲と完全解析を優先。時間はかかるが、異物・DATAを大量に持ち帰る。 |
| 暴走セツカ × 支援チカゲ | 安全装置解除 | 危険を火力に変え、支援で破綻を抑える。暴走の強化を取りすぎたら制御も補う。 |
| 殲滅セツカ × 探索チカゲ | 掃討調査 | 高速処理後に特殊CASEを発見しやすい。希少な収穫を狙いつつ、危険に応じて支援を混ぜる。 |

同じ強化は**最大Lv3**。セツカ・チカゲの単体カードは対応する傾向を1Lv育て、カード固有の効果を加算します。連携カードは**両方の傾向を各1Lv**育て、対応するシナジーの効果を1Lvにつき20%増幅します。

シナジーは、対応する両方の傾向が**各Lv2**で自動発動。連携カードを取らなくても条件を満たせば基礎効果が発動します。複数のシナジーを同時に発動でき、混成ビルドも有効です。

回収Lv2以上と十分な解析率があれば生け捕りでき、処理が10%加速し、報酬は異物1.3倍・DATA1.2倍になります。捕獲用フックや関連連携で必要な解析率を下げられます。高速処理は「基準処理時間の77%未満」で判定します。

希少異物は追加の異物収入。特殊CASE〈異相〉は通常CASEの変種で、耐久・危険が増える代わりに異物1.4倍・DATA1.35倍です。新しいマップや追加の戦闘操作はありません。

## 実装内容

- 通常CASE **9件**＋ボス **1件**。最初と最後は固定、途中8件はランごとに順序変更。難度は登場位置に合わせて段階的に上がります。
- 強化 **27種**：セツカ9 / チカゲ9 / 連携9。
- シナジー **9種**：3方向×3方向の全組み合わせ。
- 怪異の個性 **5種**：実体 / 擬態 / 反響 / 空間 / 群体。解析前の耐性、突発危険、探索報酬、範囲破壊への相性が異なります。
- 3択、BUILD、ARCHIVE、遊び方、クリア・撤退リザルト、再挑戦。
- ピンクの斧使いを**セツカ**、青の解析担当を**チカゲ**として、提供された画像を使用。画像のファイル自体は変更せず、CSSでメインビジュアル部分を表示しています。
- スマホ中心の縦長UI、デスクトップ対応、軽いバー変化・攻撃揺れ。`prefers-reduced-motion`にも対応。

## ファイル

```text
chikage-setsuka/
├── index.html           メイン画面とオーバーレイの土台
├── style.css            配色、レイアウト、軽いアニメーション
├── data.js              CASE・強化・シナジーの定義
├── script.js            シミュレーションと画面操作
├── README.md            この説明
├── assets/
│   ├── setsuka.jpg      提供画像：ピンク / 巨大斧
│   └── chikage.jpg      提供画像：青 / 解析担当
└── tests/
    └── game.test.cjs    任意の開発用テスト（Node.js標準機能のみ）
```

ゲームに必要なのは先頭4ファイルと`assets`です。READMEとテストは起動の依存関係ではありません。

`script.js`の`GameCore`は画面・タイマー・ストレージから分離されています。画面側が経過時間を渡し、ゲーム側がCASEの進行、強化待ち、次のCASE、結果を管理します。長い時間差も小さく分割し、強化待ちに入ったらそこで停止します。画面更新は約150msごとです。

数値やコンテンツを調整する入口は`data.js`、基礎速度やシナジーの計算は`script.js`の`stats()`、CASEの段階的な耐久・解析深度は`enterCase()`です。

## 確認したこと

開発用テストを実行する場合だけNode.jsが必要です。追加パッケージは不要です。

```sh
node --test tests/game.test.cjs
```

**30テスト合格**。9組み合わせ×3乱数シードの試走、27強化の上限、9連携の発動、看破、捕獲、暴走追撃、研究、危険100%での撤退、リセットを確認しています。試走のうち撤退となるビルドもあり、それは敗北結果として正常終了することを検証しています。

同じ3シードでの自動選択試走では、回収＋解析はDATA **1014〜1160**と8〜9件の捕獲、殲滅＋探索はDATA **275〜296**と2〜4件の特殊CASEでした。回収＋解析の自動稼働時間は約16.5〜16.8分、殲滅＋探索は約11〜11.8分。読み時間を含まない例であり、すべての手動プレイ結果を保証する数値ではありません。

Chromiumで、390×844の操作、320×568と1440×900での起動・選択・進行を検証。実際のボタンから強化を選び、ボス撃破、BUILDから結果への復帰、再挑戦、撤退を確認しました。一時停止とオーバーレイ中に時間が進まないこと、2倍速、横方向のはみ出しがないこと、外部通信・JavaScriptエラー・読み込み失敗がないことも確認しています。

## 注意点とMVPの検証範囲

- 現行のChrome / Edge / Safari相当の、`dialog`・`requestAnimationFrame`を使えるブラウザを想定。実ブラウザ検証はChromiumで実施しています。
- 高さの小さいスマホでは、上部のふたりと下部の操作を残し、中央のCASE・ログ欄を縦スクロールできます。
- **再読み込みで全リセット**。セーブ、オフライン進行、通信による引き継ぎはありません。同じタブの再挑戦中だけ、図鑑の開示状態と直近ランの比較用要約が残ります。
- 1×で**10〜20分程度**が目安。高速ビルドは短く、強化を読む時間や慎重な回収ビルドでは長くなります。2×では稼働時間が半分になります。画面の稼働時間には選択・停止時間を含めません。
- 危険な強化に偏ると、ボス到達前の撤退も起こります。強化を選ぶ際に危険の増加を読み、支援や解析を混ぜてください。
- データは調整しやすい初期バランスです。音、追加キャラ、装備管理、施設、マップ、ガチャ、ストーリー本編は実装範囲に含めていません。

このMVPで比較できるのは、**処理速度・捕獲数・異物収入・DATA収入・希少発見・特殊CASE・危険の安定性**です。結果に残るふたりの型と連携を見て、「次は違う育て方を試したいか」を確認できます。
