# MIMIC 現在の仕様書

更新：2026-11-03 ／ 対象：現行のWeb検証版

この文書は企画段階の目標ではなく、**今遊べるゲームの実装**を説明します。数値は調整用の仮値です。未実装・簡略化している箇所は末尾にまとめています。

## 1. ゲームの目的と1周の流れ

プレイヤーはダンジョンに固定されたミミック。押し寄せる冒険者を倒して装備・資金・魔石を集め、装備と永続強化を整え、ボスの撃破を目指します。

1. 拠点の「狩場へ進む」からステージを選ぶ。
2. 戦闘中は方向を狙い、自動攻撃とボムで敵を倒す。
3. HPが0になる、時間切れになる、またはボスを倒すと結果画面へ進む。
4. 戦利品・資金・魔石・進化ポイントを持ち帰る。拠点で装備や強化を整え、再挑戦する。

画面は16:9固定基準。ミミックは画面中央に固定され、移動しません。

## 2. 操作と戦闘

| 操作 | PC | タッチ |
|---|---|---|
| 照準 | ミミックからマウスカーソルへ向ける | 画面を触り始めた位置からドラッグした方向 |
| 通常攻撃 | 装備の間隔で自動発動 | 同じ |
| ボム | SPACEキー、または画面右下のボタン | 画面右下のボタン |

敵を自動で狙い直す機能はありません。攻撃方向をプレイヤーが指定します。戦闘画面にはHP、経過時間、撃破数、ボムの状態、戦利品の通知を表示します。設定で照準ガイド、効果音、エフェクトの一部を切り替えられます。

### 初期攻撃

初期装備は捕食系の牙「噛み砕く牙」。照準方向へ舌を伸ばし、範囲内で手前にいる敵1体を攻撃します。基礎値は威力16、間隔0.6秒、射程320です。

捕食系の対象は、向いている方向の前方・射程内で、照準線から左右68px以内にいる敵です。線から少し外れていても舌が対象へ曲がります。後方の敵は対象になりません。刃物の直線攻撃や呪術の基本判定は左右32pxです。範囲攻撃や投射物はそれぞれ別の判定を持ちます。

### ボム「破滅の供物」

照準方向へ160px進んだ位置を中心に、半径135pxの範囲へ基礎威力85の攻撃を行います。使用後20秒で再使用できます。ボムで直接倒した敵の撃破資金は3倍になります。初期状態から使用できます。

### 戦闘の進行と勝敗

- 1ランの制限時間は300秒。240秒でステージのボスが画面外から出現します。
- 制限時間内にボスを倒すと、その場でクリア。第一層クリアで第二層が解放されます。
- HPが0、または時間切れになると失敗。失敗しても取得済みの戦利品と通貨は保持します。
- 通常敵は出現予算を使って画面外から追加されます。予算の増加速度は `0.7＋経過秒数÷100＋ステージ番号×0.2`／秒です。ステージ番号は第一層が0、第二層が1。
- 敵の最大同時数は120体。通常敵のHPと攻撃力には、経過0／60／120／180／240秒でそれぞれ1.0／1.2／1.45／1.75／2.1倍が適用されます。第二層ではさらにHP1.5倍、攻撃力1.35倍です。ボスには時間倍率を適用しません。

## 4. 装備とビルド

### 装備枠

牙1、器官3、甲殻1、核1の計6枠。貢ぎ物で器官枠を1つ追加できます。牙は主攻撃を決め、器官などの装備はそれぞれの能力を追加します。装備画面では所持品を選び、対応する枠に装着します。

装備の基礎性能は装備レベルとレアリティで上昇します。画面の比較は主に牙の威力・間隔、HP・軽減率、系統数を表示します。すべての追加効果を比較する画面ではありません。

### 7つの能力系統

| 系統 | 現在の主な攻撃・効果 |
|---|---|
| 捕食 | 照準方向へ舌を伸ばす。引き寄せや周囲への追加攻撃がある。 |
| 刃物 | 前方の斬撃・貫通、照準側に偏った回転刃。 |
| 呪術 | 照準内の敵に呪印を刻み、条件により連鎖・破裂する。 |
| 毒・腐食 | 照準側に毒霧や毒の残留域を作り、継続ダメージを与える。 |
| 召喚 | 照準側に小型ミミックを展開し、照準方向へ弾を撃つ。 |
| 防御 | 軽減・回復や照準側への反撃。 |
| 魔力 | 照準方向への魔弾、または照準側への範囲攻撃。魔弾は追尾しない。 |

初期状態で捕食・刃物・魔力の装備がドロップし、残りの4系統は貢ぎ物で素材プールに追加します。同系統を2個装備すると、その系統のダメージ係数が20%上がります。4個装備では捕食の追加攻撃、刃物の複数攻撃、呪印の伝播、毒の追加効果、防御の回復、魔力の追加弾などが発動します。召喚は装備数に応じ召喚上限が増えます。

混成の例：捕食＋刃物で刃物攻撃を強化、毒＋呪術で条件を満たした敵の撃破時に周囲へ腐食、召喚＋魔力で召喚体の追加弾が発生します。

### レアリティと追加効果

| レアリティ | 追加効果の数 |
|---|---:|
| コモン | 0 |
| レア | 1 |
| エピック | 2 |
| レジェンダリー | 3 |
| ミシック | 4 |

追加効果は攻撃力、攻撃速度、射程、範囲、会心、吸血、追加弾、貫通、連鎖、継続ダメージ、HP、軽減、撃破時回復、各系統のダメージ、ドロップ率など23種。効果の段階はランダムで、高レアほど上位が出ます。

通常装備44種と伝説級装備10種をデータに収録。伝説級は固有能力を持ちます。現在のドロップ処理では、レジェンダリー以上が選ばれた場合、解放済み系統に候補があれば伝説級装備から抽選します。

### 伝説級の固有能力

| 装備 | 固有能力 |
|---|---|
| 王喰らいの舌 | 連続命中で捕食威力を上げ、追加攻撃につなげる。 |
| 千刃の胃袋 | 刃物装備の数に応じて刃物を強化し、回転刃を増やす。 |
| 呪眼の宝石 | 呪印のある敵の死亡時に、周囲へ呪印を伝える。 |
| 腐海の心臓 | 毒霧に即時ダメージを追加する。 |
| 群箱の王冠 | 同時に展開できる召喚体を増やす。 |
| 返り血の鎧 | 反撃の範囲を広げる。 |
| 月喰いのプリズム | 魔力攻撃を強力な範囲攻撃にする。 |
| 血錆の断刀 | 刃物の直線攻撃で複数の敵を斬る。 |
| 飢えた邪眼 | 呪印を周囲の敵にも刻む。 |
| 最後の外殻 | 致命傷を1回だけ耐え、HPを回復する。 |

## 5. 戦利品と通貨

| 獲得物 | 現在の入手方法 | 使い道 |
|---|---|---|
| 資金 | 敵撃破時に第一層5、第二層8。ボムで直接倒すと3倍。 | 鍛冶の強化・再抽選。 |
| 装備 | 通常敵は第一層16%、第二層23%を基本確率として抽選。ボスは確定。装備や強化で確率上昇。 | 枠に装備しビルドを変える。 |
| 魔石 | 撃破時に12%で系統を抽選して獲得。 | 装備に装着、または3個合成。 |
| 進化ポイント | ラン終了時に `撃破数÷5の整数部＋経過秒数÷30の整数部＋クリア時20`。失敗時も獲得。 | 貢ぎ物の祭壇で封印を解き、永続強化する。 |

通常ドロップのレアリティ抽選重みは第一層が72／21／6／1／0、第二層が58／26／11／4／1。順番はコモンからミシック。ボスは0／0／10／70／20です。

## 6. 鍛冶と魔石

- **強化**：資金 `25×次のレベル` を支払い装備レベルを1上げる。レベル1ごとに装備の基礎威力が12%上がる。
- **再抽選**：解放後、資金40で装備のランダム追加効果を引き直す。
- **魔石**：同じ系統・同じ段階を3個合成すると次の段階になる。合成には解放が必要で、最大5段階。
- **装着**：空きソケットに魔石を入れると、対応系統の係数が魔石の段階×5%上がる。外した魔石は返却される。
- ソケットはコモン0。レアは確率で1、エピック以上は確率で2です。

## 7. 貢ぎ物による永続強化

進化ポイントを8人への供物として捧げます。最初に狩人の「飢えの目覚め」を3ポイントで開き、そこから条件を満たしたものを順に購入します。キャラクターごとの会話・イベント・親密度はありません。

| 貢ぎ先 | 封印と前提 | 費用・効果 |
|---|---|---|
| 狩人 | 飢えの目覚め：最初から選択可能 | 3。祭壇の入口。 |
| 狩人 | 飢えた牙：飢えの目覚め | 初回8、以後8ずつ増加。攻撃力を1段階につき10%上昇、最大10。 |
| シスター | 血肉の器：飢えの目覚め | 初回8、以後8ずつ増加。最大HPを1段階につき10%上昇、最大10。 |
| 研究者 | 異形の器：飢えた牙 | 15。器官枠を1つ追加。 |
| 鍛冶屋 | 歪みの炉：飢えた牙 | 15。追加効果の再抽選を解放。 |
| 鍛冶屋 | 魔石の炉：歪みの炉 | 15。魔石の合成を解放。 |
| 黒魔法使い | 呪眼の覚醒：飢えた牙 | 15。呪術系の装備を解放。 |
| 研究者 | 腐敗の覚醒：呪眼の覚醒 | 15。毒・腐食系の装備を解放。 |
| 占い師 | 眷属の覚醒：血肉の器 | 15。召喚系の装備を解放。 |
| シスター | 甲殻の覚醒：眷属の覚醒 | 15。防御系の装備を解放。 |
| 商人 | 埋蔵された金貨：血肉の器 | 初回15、以後15ずつ増加。ラン開始資金を1段階につき10追加、最大10。 |
| 盗賊 | 収集の渇望：埋蔵された金貨 | 初回15、以後15ずつ増加。装備ドロップ率を1段階につき2ポイント追加、最大10。 |

## 8. 見た目・収集庫・セーブ

装備中の系統に応じて、本体の上に系統別パーツを重ねます。最多系統が4個以上になると色や目の表示も変化します。伝説級を初めて入手すると収集庫に記録されます。

装備、所持資金、魔石、永続強化、解放済みステージ・系統、収集庫は自動保存されます。Web版は使用したブラウザのローカル領域に保存し、別ブラウザ・別端末には自動同期されません。戦闘中のHPや経過時間は次のランに持ち越しません。

## 9. 現在の制限・未実装

- 女性キャラクターの肖像は未配置。貢ぎ物画面は仮アイコンです。会話・イベントは未実装です。
- 背景、攻撃演出、スプライト、効果音は現行の仮・検証用表現です。長時間のゲームバランス調整は未完了です。
- 盾兵の軽減は正面判定ではなく常時適用。表示・能力・追加効果の一部は簡略化されています。
- 召喚の4個セットには独立した専用能力はなく、装備数に応じた召喚上限の増加で表現されています。
- 端末やブラウザをまたぐセーブ同期、課金・広告・SDK連携はありません。
- 一部の敵・装備の表現は静止画や簡易的なアニメーションです。実機での長時間テスト、通常PCで敵120体・60fpsを維持できるかは未検証です。
